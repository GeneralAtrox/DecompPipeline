# Proof records

Each record here backs a claim that code, a test or a kept doc cites: a gate's planted wrong answers, a tool's
comparison with a reference, a work-count spec a check reads. Dated records of single runs (the October 2026 waste
audits' proofs, re-stamp sets, triage data, session timings) were taken out on 2026-11-08; they are in git history,
and what they taught is in `docs/LESSONS.md`. A kept record may name a script or data file from that set: read it
from the history.

A new record goes in `docs/proofs/<date>/` only when something will cite it. A record of a run nobody will cite
belongs in the run's own notes, not here.
